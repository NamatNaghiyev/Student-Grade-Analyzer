# Student Grade Analyzer

A simple Java application that analyzes student exam scores and generates a statistical report.

This project was developed as part of my Java Backend Development learning journey to practice arrays, loops, conditional statements, and methods.

## Features

- Count students who passed (score >= 51).
- Count students who failed (score < 51).
- Calculate the total score.
- Calculate the average score.
- Find the highest exam score.
- Display a formatted report in the console.

## Technologies

- **Language:** Java
- **IDE:** IntelliJ IDEA
- **Concepts:** Arrays, Loops, Conditions, Methods

## Example Output

```text
===== STUDENT GRADE REPORT =====
Total Students : 7
Passed         : 5
Failed         : 2
Total Score    : 469
Average Score  : 67.00
Highest Score  : 100
================================
```

## How to Run

1. Download or clone this repository.
2. Open the Java file in IntelliJ IDEA.
3. Run the `main()` method.
4. View the analysis results in the console.
